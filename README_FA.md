# امیدوار (OMIDWAR) — بستهٔ آمادهٔ استقرار

این بسته شامل وب‌اپلیکیشن FastAPI، پایگاه‌داده SQLite، PWA قابل نصب و فایل‌های Docker است. هنوز روی اینترنت منتشر نشده است؛ برای آنلاین‌شدن باید آن را به یک میزبان متصل کنید.

## استقرار آنلاین با Docker / Hostless
1. همهٔ محتویات ZIP را در ریشهٔ مخزن GitHub بارگذاری کنید.
2. در میزبان، مخزن را وصل و Build را روی Docker قرار دهید.
3. Volume دائمی به مسیر `/app/data` وصل کنید.
4. متغیرهای محیطی زیر را در پنل میزبان تنظیم کنید:
   - `ADMIN_USER` = نام کاربری مدیر دلخواه
   - `ADMIN_PASSWORD` = رمز قوی و یکتا
   - `TOKEN_SECRET` = رشتهٔ تصادفی قوی حداقل 32 کاراکتر
   - `DATABASE_PATH` = `/app/data/omidwar.db`
   - `SMS_ENABLED` = `false`
5. پورت برنامه از متغیر `PORT` میزبان خوانده می‌شود (پیش‌فرض 8000). مسیر بررسی سلامت `/health` است.
6. پس از استقرار، آدرس HTTPS را باز کنید و ورود مدیر را آزمایش کنید.

## اجرای محلی
1. `.env.example` را به `.env` کپی کنید.
2. در `.env` مقادیر `ADMIN_PASSWORD` و `TOKEN_SECRET` را عوض کنید؛ از رمز نمونه استفاده نکنید.
3. اجرا: `docker compose up --build -d`
4. بازکردن: `http://localhost:8000`
5. توقف: `docker compose down` (داده‌ها در Volume باقی می‌مانند). برای حذف داده‌ها نیز باید Volume را جداگانه حذف کنید.

## نصب روی گوشی بدون APK (PWA)
پس از انتشار روی HTTPS، سایت را با Chrome در اندروید باز کنید و از منو گزینهٔ «نصب برنامه» یا «افزودن به صفحه اصلی» را انتخاب کنید. این روش به APK نیاز ندارد.

## APK اندروید
پوشهٔ جداگانهٔ `android-app-source` در بسته، پروژهٔ Android Studio است. ابتدا باید سایت آنلاین و HTTPS شود؛ سپس آدرس نهایی را در `MainActivity.java` جایگزین `APP_URL` کنید و از Android Studio فایل APK را بسازید. بنابراین APK نهایی در این ZIP نیست؛ بدون آدرس سایت نهایی نمی‌توان اپلیکیشن اندروید متصل به سرور را تکمیل و آزمایش کرد.

## پیامک
ارسال واقعی به‌صورت پیش‌فرض خاموش است. برای فعال‌سازی باید حساب و API ارائه‌دهنده، Sender ID، پوشش شماره‌ها و متن پیام آزمایش شوند. فقط پس از تأیید ارائه‌دهنده، متغیرهای `SMS_USERNAME` و `SMS_PASSWORD` را در تنظیمات محرمانهٔ میزبان قرار دهید و سپس `SMS_ENABLED=true` کنید. کلیدها را در GitHub یا داخل برنامهٔ اندروید قرار ندهید. پاسخ «accepted» صرفاً پذیرش درخواست توسط سرویس است و تضمین تحویل نیست.

## نکات مهم
- داده‌های محصلان و نمرات حساس‌اند؛ فقط با HTTPS استفاده کنید.
- قبل از استفادهٔ واقعی، پشتیبان‌گیری منظم و بازبینی امنیتی انجام دهید.
- نسخهٔ فعلی تک‌مدیره است و برای چند مکتب/مؤسسه به جداسازی داده و معماری کامل‌تر نیاز دارد.
- `DATABASE_PATH` در Docker روی `/app/data/omidwar.db` تنظیم شده و باید Volume دائمی روی `/app/data` وصل باشد.
