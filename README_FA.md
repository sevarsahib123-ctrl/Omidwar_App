# پروژه اندروید امیدوار

این پوشه پروژهٔ منبع Android Studio برای ساخت APK است؛ هنوز APK نهایی نیست.

## قبل از ساخت APK
1. ابتدا نسخهٔ آنلاین سرور را روی یک میزبان HTTPS منتشر کنید.
2. فایل `app/src/main/java/com/omidwar/app/MainActivity.java` را باز کنید.
3. مقدار `APP_URL` را از آدرس نمونه به آدرس واقعی HTTPS سایت امیدوار تغییر دهید.
4. پروژه را در Android Studio باز و Sync کنید.
5. از منوی Build گزینهٔ Build APK(s) را انتخاب کنید.

برای انتشار عمومی، APK باید با کلید امضای اختصاصی (release keystore) امضا شود. کلید و رمز آن را در مخزن GitHub قرار ندهید.
