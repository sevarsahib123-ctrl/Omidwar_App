# OMIDWAR — مدیریت نمرات محصلان

این Space نسخهٔ وب آزمایشی سیستم امیدوار را اجرا می‌کند.

## تنظیمات ضروری

از تب **Settings → Variables and secrets** این مقادیر را اضافه کنید:

- `ADMIN_USER`: نام کاربری مدیر
- `ADMIN_PASSWORD`: یک رمز قوی و منحصربه‌فرد
- `TOKEN_SECRET`: یک مقدار تصادفی و طولانی (حداقل 32 کاراکتر)
- `SMS_ENABLED`: مقدار `false` را نگه دارید تا سرویس پیامک را جداگانه آزمایش و تأیید کنید.

هرگز رمزها یا کلیدهای واقعی را در فایل‌ها یا مخزن عمومی قرار ندهید.

## داده‌ها و حریم خصوصی

به‌صورت پیش‌فرض برنامه از SQLite در مسیر `/data/omidwar.db` استفاده می‌کند. برای نگه‌داری داده‌ها پس از راه‌اندازی مجدد، در صورت دسترس بودن، Storage پایدار را به Space وصل کنید و مسیر آن را `/data` قرار دهید. بدون ذخیره‌سازی پایدار، اطلاعات ممکن است از بین بروند.

این نسخه پیش از استفادهٔ واقعی با اطلاعات محصلان نیازمند بررسی امنیتی و حریم خصوصی است. برای آزمایش، فقط از داده‌های ساختگی استفاده کنید. ارسال پیامک به‌صورت پیش‌فرض خاموش است.

بررسی سلامت برنامه: `/health`
